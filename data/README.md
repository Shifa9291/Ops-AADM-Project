# Data

Place the project dataset here as **`OPS_DS1.csv`** (1,000 transactions × 38 fields).

```
data/
└── OPS_DS1.csv
```

The alternative Excel version (`Supply_Chain_Efficiency_OPS_DS1.xlsx`) also works:

```bash
python run_analysis.py --data data/Supply_Chain_Efficiency_OPS_DS1.xlsx
```

> **Publishing note:** this is course-provided data. Check with your instructor before
> making the raw file public. To keep it out of the repo, uncomment `data/*.csv` in `.gitignore`.
